# 奶蛙 MBTI 人格测试

30 道小题，测出你是奶蛙家族的哪一只。纯静态站点，零运行时依赖。

> 本版由「奶龙 MBTI 测试」改名而来：角色名统一改为**奶蛙**，题目里的**小七**改为**小八**，并接入了作者提供的奶蛙素材作为结果配图。


## 数据驱动

改内容只需动 `data/` 下三个文件：

| 文件 | 内容 |
|---|---|
| `config.json` | 标题、副标题、引导语、署名（分享图水印）、平局规则 |
| `questions.json` | 30 题；每个选项带 `dims`（如 `["E"]` 或 `["S","E"]`），dims 是内部计分标签，不展示给用户 |
| `personalities.json` | 16 型人设：`cn` / `group` / `figure` / `desc` / `quote` |

`src/engine.js` 与题量、选项数无关：选项 `dims` 累加 → 四维各自比大小 → 组合 4 字母。

## 结果配图

- 每个型号的配图由 `personalities.json` 的 `figure` 字段指定，文件放在 `public/wafrog/`。
- **文件名即型号**：已启用的配图统一命名为 `<型号>人格.jpg`（如 `ESTP人格.jpg`）；未被指派的素材保留语义名，以便区分。
- **一型一图、宁缺毋滥**：凑不上合适素材的型号 `figure` 留 `null`，会回退到 `public/figures/` 的原创占位图，并在图下标注「该型配图待补」。
- 当前进度：**16 / 16 已配齐**（2026-10-11 收到作者补充的 `勇敢奶蛙.jpg`，ESTP 冒险闯祸奶蛙已配上 `ESTP人格.jpg`，占位图不再出现）。
- 完整映射、指派依据与未用素材清单见 [`docs/奶蛙配图映射表.md`](docs/奶蛙配图映射表.md)。
- `npm test` 会强制校验：型号合法、图片文件存在、**同一张图不得被两个型号共用**。

## 页面背景

- 首屏（及全站）背景图由 `config.json` → `display.background.image` 指定，文件放在 `public/bg/`；留空则回退纯色底（`--bg`）。
- 作者给的原图是 859×861 的方图（白底 + 底部一条地影），**不能直接当网页背景**：`cover` 会把它放大 1.7 倍（发虚），方图在宽屏被裁掉头顶、在窄屏又露出地影。
- 所以用 `scripts/make-background.py` 合成成 1920×1000 的网页底图：角色**按原始像素**放置（不放大 → 清晰）、底边渐隐化掉地影、**底色取与原图一致的纯白**（取奶白色的话，画布与原图交界处会出现一条肉眼可见的色差方框）。
- favicon 也用这只奶蛙（`public/bg/favicon.png`，头部 128×128 裁切）。**原先界面上那个 🐸 emoji 吉祥物与 🐸 favicon 已一并删除。**

## 计分与平局

- 每选一个选项，给它的 `dims` 里每个字母 +1。
- 四个维度（E/I、S/N、T/F、J/P）各自比较两极得分，高者胜出。
- 若两极得分相等（罕见），按 `config.scoring.tieBreak` 判定（默认 `I / N / F / P`）。
- 结果页展示四维倾向百分比与所有四个维度的强弱。

## 关于素材与 IP

- `奶蛙图片/` 是作者提供的**原始素材库**（27 张 = 26 张人格素材 + 1 张界面背景图），不参与构建；`public/wafrog/` 是副本，其中已启用的 16 张按 `<型号>人格.jpg` 命名，未启用的 10 张保留语义名。
- 「奶蛙」形象与这批素材的著作权/授权情况请自行确认；本项目仅做技术集成，未对素材做二次创作。
- 兜底占位图由 `scripts/generate-figures.mjs` 生成，是原创几何造型，不含任何第三方形象素材。
